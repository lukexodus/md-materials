## Package Naming


Packages (or namespaces) group related modules and classes. They act as the root hierarchy for project organization.

**Key Points**

- **Single Word/Lowercase:** Package names should ideally be single, short, lowercase words.
    
- **Domain Reverse Notation:** In ecosystems like Java, use reverse domain names to ensure global uniqueness (e.g., `com.company.project.module`).
    
- **Avoid Underscores:** While allowed in some languages, standard convention often prefers flat naming or dot separation (e.g., `utilities` rather than `my_utilities`).
    
- **Layer Identification:** Packages often represent architectural layers (e.g., `services`, `models`, `controllers`, `utils`).
    

**Example**

- **Poor:** `myClasses`, `TheProject`, `utils_stuff`
    
- **Better:** `net.google.common`, `org.apache.http`, `pandas`
