## Continuous Uniform Distribution

### Definition

A continuous random variable $X$ follows a continuous uniform distribution over interval $[a, b]$ if its probability density is constant across that interval and zero elsewhere. Every sub-interval of equal length within $[a, b]$ has equal probability of containing $X$.

Notation: $X \sim \text{Uniform}(a, b)$ or $X \sim U(a, b)$.

### Probability Density Function

$$f(x) = \begin{cases} \dfrac{1}{b - a} & a \le x \le b \\ 0 & \text{otherwise} \end{cases}$$

### Cumulative Distribution Function

$$F(x) = \begin{cases} 0 & x < a \\ \dfrac{x - a}{b - a} & a \le x \le b \\ 1 & x > b \end{cases}$$

### Mean and Variance

$$E[X] = \frac{a + b}{2}$$

$$\text{Var}(X) = \frac{(b - a)^2}{12}$$

**Key Points**
- Unlike the discrete case, $P(X = x)$ for any single point $x$ is zero — probability is only meaningful over intervals.
- The mean is the midpoint of the interval, same structural form as the discrete uniform case.
- Variance depends only on interval width $(b - a)$, not on location.

### Standard Uniform Distribution

The special case $a = 0$, $b = 1$ is called the standard uniform distribution, $U(0, 1)$:

$$f(x) = 1, \quad 0 \le x \le 1$$

$$E[X] = 0.5, \quad \text{Var}(X) = \frac{1}{12}$$

This is the foundational distribution used to generate samples from other distributions via transformation methods.

### Entropy

$$H(X) = \log(b - a)$$

[Inference] As with the discrete case, the continuous uniform distribution maximizes differential entropy among all continuous distributions with support strictly bounded to $[a, b]$, since it encodes no preference for any sub-region. This is a standard result in information theory but is presented here as [Inference] since no specific source is being cited.

### Example

$X \sim \text{Uniform}(2, 10)$

$$f(x) = \frac{1}{10 - 2} = \frac{1}{8}, \quad 2 \le x \le 10$$

$$E[X] = \frac{2 + 10}{2} = 6, \quad \text{Var}(X) = \frac{(10-2)^2}{12} = \frac{64}{12} \approx 5.333$$

$$P(4 \le X \le 7) = F(7) - F(4) = \frac{7-2}{8} - \frac{4-2}{8} = \frac{5}{8} - \frac{2}{8} = \frac{3}{8} = 0.375$$
