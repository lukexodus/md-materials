## Statistical Tests for Stationarity

### Definition

Statistical tests for stationarity are hypothesis-testing procedures used to assess, from observed sample data, whether a time series is likely generated by a stationary process. These tests provide statistical evidence rather than certainty, since they rely on finite samples and specific null-hypothesis structures.

### Augmented Dickey-Fuller (ADF) Test

The ADF test evaluates the null hypothesis that a unit root is present in the series (indicating non-stationarity), against the alternative hypothesis of stationarity. It extends the original Dickey-Fuller test by including lagged difference terms to account for higher-order autocorrelation in the error structure.

$$\Delta X_t = \alpha + \beta t + \gamma X_{t-1} + \sum_{i=1}^{k} \delta_i \Delta X_{t-i} + \epsilon_t$$

The test statistic is based on the estimated coefficient $\gamma$. The null hypothesis is $\gamma = 0$ (unit root present, non-stationary); the alternative is $\gamma < 0$ (stationary).

$$H_0: \gamma = 0 \quad \text{(unit root, non-stationary)}$$



$$H_1: \gamma < 0 \quad \text{(stationary)}$$

### KPSS Test

The Kwiatkowski-Phillips-Schmidt-Shin (KPSS) test structures its hypotheses in the opposite direction from the ADF test: the null hypothesis is stationarity, and the alternative is the presence of a unit root.

$$H_0: \text{series is stationary (around a level or trend)}$$



$$H_1: \text{series has a unit root (non-stationary)}$$

### Phillips-Perron (PP) Test

The Phillips-Perron test addresses the same null hypothesis structure as the ADF test (unit root present) but uses a non-parametric correction for serial correlation and heteroscedasticity in the errors, rather than the parametric lagged-difference terms used in ADF. ### Worked Example: Applying ADF and KPSS

**Example**

```python
import numpy as np
from statsmodels.tsa.stattools import adfuller, kpss

np.random.seed(10)
n = 200

stationary_series = np.random.normal(0, 1, n)
random_walk = np.cumsum(np.random.normal(0, 1, n))

adf_stat = adfuller(stationary_series)
adf_rw = adfuller(random_walk)

kpss_stat = kpss(stationary_series, regression='c')
kpss_rw = kpss(random_walk, regression='c')

print("ADF p-value (stationary series):", adf_stat[1])
print("ADF p-value (random walk):", adf_rw[1])
print("KPSS p-value (stationary series):", kpss_stat[1])
print("KPSS p-value (random walk):", kpss_rw[1])
```

### Structural Break Tests

Standard unit-root tests such as ADF assume no structural break in the series. When a structural break is suspected, tests such as the Zivot-Andrews test allow for a single unknown break point in the trend or intercept while testing for a unit root. ### Variance Ratio Test

The variance ratio test evaluates stationarity-related properties by comparing the variance of $k$-period returns to $k$ times the variance of 1-period returns; under a random walk null hypothesis, this ratio is expected to equal 1. ### Interpreting p-values in Stationarity Testing

A low p-value in the ADF test leads to rejection of the unit-root null hypothesis, providing statistical evidence consistent with stationarity, though it does not constitute certainty of stationarity. [Inference] This distinction — that a hypothesis test provides statistical evidence rather than proof — is a general property of frequentist hypothesis testing, reasoned from the standard logical structure of null hypothesis significance testing, not a claim specific to any single external source. Test conclusions are also subject to Type I and Type II error rates, and small sample sizes can reduce the reliability of test conclusions in ways that are not quantifiable without knowing the specific sample size and underlying data-generating process.

### Limitations Common to Unit Root Tests

- Statistical power to detect non-stationarity can be limited in small samples, meaning a test may fail to reject a false null hypothesis; the specific power for a given sample size and effect size is not something that can be stated without a formal power analysis for that specific case.
- These tests generally assume a specific parametric structure for the null and alternative hypotheses (e.g., presence or absence of a linear trend term); misspecifying this structure (e.g., omitting a trend term when one is present) can lead to incorrect conclusions, though the specific consequence for any given series is not something that can be generalized without case-specific analysis.
- Structural breaks not accounted for by standard tests can lead to spurious conclusions of non-stationarity when a break, rather than a genuine unit root, is the actual source of apparent non-stationarity in the series.
